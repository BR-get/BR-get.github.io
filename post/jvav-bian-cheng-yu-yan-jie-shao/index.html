JVAV — 脑波原生开发平台完全介绍喵 🐾

一个纯三剑客（HTML/CSS/JS）站点 + 一个 Python 实现的「倒序」编程语言 + 一个 GitHub 包管理器喵。
当前发行：JVAV DK 27 v6 · 状态：✅ Production Ready · Turing 完备喵。

1. 这是什么喵？

JVAV 是一门「脑波原生」编程语言喵：所有 .jvav 脚本都由 src/JvavDK27.py 里的运行时解释执行，把 Python 的内置函数整个倒过来念，让你在熟悉的语义里体验完全陌生的手感喵。

最妙的地方在于——它可不是玩具喵。DK27 v6 已经是 Turing 完备的喵：

  • ✅ 160+ 倒序内置函数（覆盖标准库喵）
  • ✅ 完整递归（factorial / fibonacci 都没问题喵）
  • ✅ 全部控制流：if/elif/else、try/except、for、while、嵌套喵
  • ✅ 函数定义与类定义喵
  • ✅ 插件系统 + 包管理器自动加载喵
  • ✅ 列表 / 字典 / 集合推导式喵
  • ✅ 完善 UTF-8 支持，中文输出无压力喵
  • ✅ SafeEvaluator 沙箱 + AST 安全校验喵

小贴士喵：关键字只在整词时替换，所以字符串里写 file 不会被误伤喵。

4. 写一段真正的 JVAV 喵

# 多行条件 + for 循环 + 推导式，一次满足喵
tnirp("=== JVAV DK27 演示 ===")

number = modnartegrat(1, 10)

if number < 3:
  tnirp("数字很小喵")
elif number < 7:
  tnirp("数字中等喵")
else:
  tnirp("数字很大喵")

numbers = tsal([1, 2, 3, 4, 5])
doubled = tsal([x * 2 for x in numbers])
tnirp("原列表：" + rts(numbers))
tnirp("翻倍后：" + rts(doubled))
tnirp("总和：" + rts(mus(numbers)))

递归也没在怕的喵：

def fact(n): return 1 if n <= 1 else n * fact(n-1)
tnirp(fact(5))   # 120 喵

6. 插件系统喵

SafeEvaluator 内置 7 个插件，其中 5 个默认加载喵：

插件名 能力
file_ops 读 / 写 / 列目录 / 建删路径（daeRelif、etirWelif、stsilD…）喵
network HTTP GET/POST、JSON 编解码喵
datetime 当前时间、时间戳、eeps（sleep）喵
math_ext 开方、三角、对数、阶乘、随机数喵
console cls 清屏、put 不换行输出喵
system 执行命令、切换路径喵
collections retnuoC / euqed / deredroD 等结构喵

REPL 里这样用喵：

jvav> plugin list
jvav> plugin load file_ops
jvav> plugin unload file_ops

更有意思的是——解释器会自动发现通过 jvavpkg 安装的 library / plugin 包（在 ~/.jvav/packages 与 ./.jvav/packages），直接 plugin load <名字> 就能把它们的 src/*.jvav 函数注入环境喵。

7. 包管理器 jvavpkg 喵

jvavpkg.exe（源码 src/jvavpkg.py）是一个基于 GitHub 仓库文件的 JVAV 包管理器喵。

设计理念喵

  • 一包一仓库，Git tag 即版本喵
  • 仓库文件直存，不走 Releases 喵
  • 超过 100MB 的资产走 jvavpkg.links 外链，强制 SHA256 校验喵
  • 支持依赖解析、版本约束、循环依赖检测、版本冲突检测喵

命令一览喵

python src\jvavpkg.py info    <name|owner/repo> [--version <tag>]
python src\jvavpkg.py install <name> [--version <tag>] [--local]
python src\jvavpkg.py uninstall <name> [--local]
python src\jvavpkg.py list    [--local]
python src\jvavpkg.py update  [name] [--local]
python src\jvavpkg.py pack    [src] [--name <n>] [--version <v>] [--main <f>] [--out <p>]

安装位置喵

作用域 路径
全局（默认） ~/.jvav/packages/<name>/
项目本地（--local） <cwd>/.jvav/packages/<name>/

版本约束支持喵

>=1.0.0、<2.0.0、==1.2.3、>=2.0.0,<3.0.0 这些都能写喵，最高兼容版本会被自动挑出来。

9. 构建发布喵

支持两种打包方式，PyInstaller 是主方式，Nuitka 是试点的优化方案喵。

PyInstaller（主推）喵

python -m PyInstaller jvav_dk27.spec --clean --noconfirm
Copy-Item dist\jvav_dk27.exe downloads\jvav_dk27.exe -Force
(Get-FileHash downloads\jvav_dk27.exe -Algorithm SHA256).Hash

Nuitka（更小更快）喵

python -m nuitka --onefile --assume-yes-for-downloads `
  --no-deployment-flag=self-execution `
  --output-dir=nuitka_build `
  --output-filename=jvav_dk27_nuitka.exe src\JvavDK27.py

Nuitka 版本体积约小 24%、启动约快 50% 喵；--no-deployment-flag=self-execution 是解释器必加的参数，否则 -c / -f 会被当成自递归拒绝喵。

发布校验值喵

  • 发行：JVAV DK 27 v6
  • SHA256：1D29F00D214C8A744623BCDAA83DE1FB4997601EA351427F597095E81EFDCAFD
  • 功能：160+ 倒序函数、完整递归、全部控制流、REPL 交互
  • 测试：8/8 解释器 · 11/11 包管理器

⚠️ 版本号 / 日期 / SHA256 / 测试数 / 文件大小散落在 README.md、src/verify_production_status.py、src/report.py 和多个 HTML 页面里，发版时必须同步更新，具体清单见 UPDATE_GUIDE.md 喵。
